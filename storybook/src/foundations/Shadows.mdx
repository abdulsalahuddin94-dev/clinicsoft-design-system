# Shadows
Figma page `➜ Shadows`. 12 effect styles, Tailwind offsets with a higher black alpha so they read on dark surfaces. Shadows only on overlays: Menu and Tooltip `shadow-md`, Toast `shadow-lg`, Modal `shadow-xl`. `focus-ring` (inset 2px) is for inputs, menu and sidebar rows; `focus-ring-offset` (2px gap + ring) for buttons and controls.

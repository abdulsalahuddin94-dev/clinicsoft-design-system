# Icons
Figma page `➜ Icons`. 40 Lucide outline icons, 24px, stroke 2, named `Icon/<Name>`. Color comes from the parent's `color/icon/*` token; sizes 16, 20, 24. Components expose them through INSTANCE_SWAP properties (`Leading Icon`, `Trailing Icon`, `Icon`); the control options are these exact names.

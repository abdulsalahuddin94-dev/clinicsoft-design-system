# Typography
Figma page `➜ Typography`. Poppins, 40 text styles named `{size}/{weight}`. Family, size, line height, letter spacing and weight are bound to the **Typography** variables, which have Desktop, iPad and Mobile modes (switch **Mode** in the toolbar). CSS class = style name: `sm/Semi Bold` → `.ts-sm-semi-bold`.
